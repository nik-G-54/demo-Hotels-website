# VÉLARIS — Luxury Hotel & Banquets Website

Responsive luxury landing page built with plain HTML, CSS and JavaScript.

## Included
- Cinematic hero and animated preloader
- Deep obsidian/forest-green palette with champagne-gold accents
- Sticky glass header, responsive mobile navigation and active section state
- Scroll reveals, count-up statistics, subtle cursor glow, magnetic buttons and parallax hero
- Room cards with modal details, banquet showcase, dining section and horizontal gallery controls
- Enquiry form validation and demo feedback
- Responsive mobile layouts and reduced-motion support

## Run locally
Extract the ZIP and open `index.html` in a browser. VS Code Live Server is recommended. Internet access is required for Google Fonts and remote Unsplash demo photography.

## Before commercial use
Replace the fictional brand, contact details, rates, venue capacity and all placeholder claims. Use client-approved/licensed photography. The enquiry form does not transmit data; connect it to a backend/CRM or form service. Replace the video placeholder with the real hotel film, and add real booking integration, privacy and terms pages as needed. Test on mobile and the client's hosting before launch.
